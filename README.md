# jahpoddesistir

Landing divertida da família **jahpod**: *já posso desistir?*

A resposta é sempre **NÃO** — com frases motivacionais/debochadas a cada clique. Estuda pra ficar rico logo.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Sprite 8-bit em SVG (`image-rendering: pixelated`)
- Lógica 100% client-side (sem backend)

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).
